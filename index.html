Chapter 1: Linear Algebra

Fondasi Matematika untuk Machine Learning & Graphics

1.1 Matrix & Vector Operations

Linear Algebra adalah fondasi utama dalam computer science modern, khususnya dalam machine learning, computer graphics, dan game development. Setiap pixel di layar, setiap model neural network, dan setiap transformasi 3D didasarkan pada operasi matrix dan vector.

Matrix A dengan dimensi m×n:

A = [a₁₁ a₁₂ ... a₁ₙ]

[a₂₁ a₂₂ ... a₂ₙ]

[... ... ... ...]

[aₘ₁ aₘ₂ ... aₘₙ]

Real-world Example: Dalam CNN (Convolutional Neural Networks), setiap layer operasi adalah matrix multiplication. Transformasi gambar 224×224 pixels direpresentasikan sebagai matrix 224×224 yang kemudian diproses melalui filters (matrices) untuk ekstraksi features.

Medium

1.2 Eigenvalue & Eigenvector

Eigenvalue dan eigenvector adalah konsep fundamental dalam analisis matrix. Untuk matrix persegi A, vektor non-zero v dan scalar λ yang memenuhi Av = λv disebut eigenvector dan eigenvalue.

JavaScript - Menghitung Eigenvalue 
// Eigenvalue computation (simplified)
function powerIteration(matrix, iterations = 100) {
    let v = matrix[0].map(() => Math.random());
    
    for (let i = 0; i < iterations; i++) {
        // Multiply matrix by vector
        let Av = matrixMultiply(matrix, v);
        
        // Normalize
        let norm = Math.sqrt(
            Av.reduce((sum, x) => sum + x*x, 0)
        );
        v = Av.map(x => x / norm);
    }
    
    // Eigenvalue adalah Av[0] / v[0]
    let Av = matrixMultiply(matrix, v);
    return Av[0] / v[0];
}

Use Case: PCA (Principal Component Analysis) menggunakan eigenvector dari covariance matrix untuk dimensionality reduction. Ini digunakan dalam face recognition, image compression, dan data analysis.

Hard

1.3 PCA & Dimensionality Reduction

Principal Component Analysis (PCA) adalah teknik untuk mengurangi dimensi data sambil mempertahankan informasi penting. Dengan menemukan eigenvector dari covariance matrix, kita dapat mengidentifikasi arah varians maksimal dalam data.

Covariance Matrix:

Cov(X) = (1/n) * X^T * X

Dimensionality Reduction:

X_reduced = X * W (W = eigenvectors)

Python - PCA Implementation 
import numpy as np

def pca(X, n_components):
    # Center data
    X_centered = X - np.mean(X, axis=0)
    
    # Covariance matrix
    cov_matrix = np.cov(X_centered.T)
    
    # Eigendecomposition
    eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)
    
    # Sort by eigenvalues
    idx = eigenvalues.argsort()[::-1]
    eigenvectors = eigenvectors[:, idx[:n_components]]
    
    # Project
    return X_centered @ eigenvectors

Industri Real-world: Netflix menggunakan PCA untuk mengurangi dimensi movie features sebelum melatih recommendation system. Hasilnya adalah prediksi yang lebih cepat dengan akurasi tinggi.

Hard

Chapter 2: Calculus

Fondasi Optimisasi & Machine Learning

2.1 Derivative & Gradient

Calculus adalah jantung dari machine learning. Derivative mengukur laju perubahan fungsi. Dalam konteks ML, gradient adalah vector derivative yang menunjukkan arah peningkatan fungsi loss paling cepat. Backpropagation algorithm sepenuhnya bergantung pada chain rule dari calculus.

Derivative:

f'(x) = lim(h→0) [f(x+h) - f(x)] / h

Gradient (multivariable):

∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]

Real-world Application: Setiap neural network menggunakan gradient untuk update weights. Jika loss = 0.5, dan gradient w.r.t. weight = -0.1, maka weight update = weight - learning_rate * (-0.1).

Medium

2.2 Gradient Descent & Optimization

Gradient Descent adalah algoritma optimisasi iteratif yang digunakan untuk menemukan minimum fungsi. Algoritma ini adalah dasar dari semua algoritma training modern seperti Adam, RMSprop, dan SGD.

JavaScript - Gradient Descent 
function gradientDescent(weights, data, labels, learningRate, epochs) {
    const n = data.length;
    
    for (let epoch = 0; epoch < epochs; epoch++) {
        // Compute predictions
        let predictions = data.map(x => 
            weights[0] + weights[1] * x[0]
        );
        
        // Compute loss
        let loss = predictions.reduce((sum, pred, i) => 
            sum + Math.pow(pred - labels[i], 2), 0
        ) / n;
        
        // Compute gradients
        let grad0 = 0, grad1 = 0;
        for (let i = 0; i < n; i++) {
            let error = predictions[i] - labels[i];
            grad0 += 2 * error / n;
            grad1 += 2 * error * data[i][0] / n;
        }
        
        // Update weights
        weights[0] -= learningRate * grad0;
        weights[1] -= learningRate * grad1;
        
        if (epoch % 100 === 0) console.log(`Epoch ${epoch}: Loss = ${loss}`);
    }
    
    return weights;
}

Industry Case: Google menggunakan advanced gradient descent variants untuk training BERT model dengan 340 million parameters. Efficiency dalam gradient computation adalah kunci.

Hard

2.3 Jacobian & Hessian Matrix

Jacobian adalah matrix dari semua first-order partial derivatives. Hessian adalah matrix dari second-order partial derivatives. Keduanya penting untuk understanding convergence dan optimization landscape.

Jacobian Matrix J:

J = [∂f₁/∂x₁ ∂f₁/∂x₂ ... ∂f₁/∂xₙ]

[∂f₂/∂x₁ ∂f₂/∂x₂ ... ∂f₂/∂xₙ]

Hessian Matrix H:

H = [∂²f/∂x₁² ∂²f/∂x₁∂x₂ ...]

[∂²f/∂x₂∂x₁ ∂²f/∂x₂² ...]

Hard

Chapter 3: Discrete Mathematics

Algoritma, Struktur Data & Graph Theory

3.1 Graph Theory Fundamentals

Graph Theory adalah study tentang graphs, yang terdiri dari vertices (nodes) dan edges (connections). Hampir setiap problem kompleks di computer science dapat direpresentasikan sebagai graph: social networks, routing algorithms, dependency resolution, dan recommendation systems.

Graph Representation:

G = (V, E) di mana:

V = set of vertices

E = set of edges (pairs of vertices)

Degree: deg(v) = jumlah edges yang connect ke vertex v

Real-world Example: Facebook graph memiliki 3 billion vertices (users) dan 150+ billion edges (friendships). Graph algorithm seperti BFS digunakan untuk "people you may know" recommendations.

Easy

3.2 Graph Algorithms: DFS & BFS

Depth-First Search (DFS) dan Breadth-First Search (BFS) adalah dua fundamental graph traversal algorithms. DFS menggunakan stack dan traverse ke depth maksimal dulu, sedangkan BFS menggunakan queue dan explore level demi level.

JavaScript - DFS & BFS Implementation 
// Adjacency List Graph
class Graph {
    constructor() {
        this.graph = new Map();
    }
    
    addEdge(u, v) {
        if (!this.graph.has(u)) this.graph.set(u, []);
        this.graph.get(u).push(v);
    }
    
    // DFS - menggunakan recursion/stack
    dfs(start, visited = new Set()) {
        visited.add(start);
        console.log(start);
        
        if (this.graph.has(start)) {
            for (let neighbor of this.graph.get(start)) {
                if (!visited.has(neighbor)) {
                    this.dfs(neighbor, visited);
                }
            }
        }
    }
    
    // BFS - menggunakan queue
    bfs(start) {
        const visited = new Set([start]);
        const queue = [start];
        
        while (queue.length > 0) {
            let node = queue.shift();
            console.log(node);
            
            if (this.graph.has(node)) {
                for (let neighbor of this.graph.get(node)) {
                    if (!visited.has(neighbor)) {
                        visited.add(neighbor);
                        queue.push(neighbor);
                    }
                }
            }
        }
    }
}

3.3 Combinatorics & Logic

Combinatorics adalah study tentang counting dan arrangement. Permutasi, kombinasi, dan generating sets adalah fundamental untuk solving optimization problems dan understanding complexity.

Permutation: P(n,r) = n! / (n-r)!

Combination: C(n,r) = n! / (r!(n-r)!)

Boolean Logic:

AND (∧): True hanya jika keduanya True

OR (∨): True jika minimal satu True

NOT (¬): Negasi dari nilai

Industry Use: Combinatorics digunakan dalam cryptography untuk menghitung possible keys, dalam algorithm design untuk counting solutions, dan dalam networking untuk routing path calculation.

Medium

Chapter 4: Probability & Statistics

Data Analysis & Machine Learning Foundations

4.1 Bayesian Theorem & Inference

Bayes' theorem adalah fundamental dalam probabilistic reasoning dan machine learning. Formula ini memungkinkan kita untuk compute P(A|B) dari P(B|A), yang adalah dasar dari Bayesian networks dan probabilistic models.

Bayes' Theorem:

P(A|B) = P(B|A) * P(A) / P(B)

di mana:

P(A|B) = posterior probability

P(B|A) = likelihood

P(A) = prior probability

P(B) = evidence

Real-world Application: Spam email filters menggunakan Naive Bayes untuk classify emails. P(Spam|Words) dihitung dari historical data tentang seberapa sering kata-kata tertentu muncul di spam emails.

Medium

4.2 Gaussian Distribution & Normal Distribution

Gaussian (Normal) Distribution adalah distribution paling penting dalam statistics dan ML. Hampir semua machine learning algorithms assume atau menggunakan Gaussian distribution untuk model assumptions. Central Limit Theorem menyatakan bahwa sum dari random variables akan approximately normally distributed.

Gaussian PDF:

f(x) = (1 / (σ√(2π))) * e^(-(x-μ)² / (2σ²))

di mana:

μ = mean (center)

σ = standard deviation (spread)

JavaScript - Gaussian Distribution 
function gaussianPDF(x, mean, stdDev) {
    const numerator = Math.exp(
        -Math.pow(x - mean, 2) / (2 * Math.pow(stdDev, 2))
    );
    const denominator = stdDev * Math.sqrt(2 * Math.PI);
    return numerator / denominator;
}

// Generate Gaussian distribution
function generateGaussian(mean, stdDev, samples) {
    let result = [];
    for (let i = 0; i < samples; i++) {
        // Box-Muller transform untuk generate normal random
        let u1 = Math.random();
        let u2 = Math.random();
        let z0 = Math.sqrt(-2 * Math.log(u1)) * 
                 Math.cos(2 * Math.PI * u2);
        result.push(mean + z0 * stdDev);
    }
    return result;
}

4.3 Markov Chain & Entropy

Markov Chain adalah model probabilistik di mana state masa depan hanya bergantung pada state saat ini, bukan historical states. Entropy mengukur uncertainty atau randomness dalam sistem. Shannon Entropy fundamental untuk information theory, compression, dan cryptography.

Markov Property:

P(Xₙ₊₁ | Xₙ, Xₙ₋₁, ..., X₁) = P(Xₙ₊₁ | Xₙ)

Shannon Entropy:

H(X) = -Σ P(x) * log₂(P(x))

Use Case: Google PageRank algorithm adalah Markov Chain yang models web surfing. Entropy digunakan dalam decision trees untuk measuring information gain di setiap split.

Hard

Chapter 5: Computational Complexity

Algorithm Analysis & Performance Optimization

5.1 Big O Notation & Complexity Analysis

Big O notation adalah mathematical way untuk describe algorithm's running time berdasarkan input size. Understanding complexity adalah crucial untuk menulis scalable code. O(1) adalah constant time, O(n) adalah linear, O(n²) adalah quadratic, O(log n) adalah logarithmic.

Big O Classes (dari fastest ke slowest):

O(1) - Constant

O(log n) - Logarithmic (binary search)

O(n) - Linear (single loop)

O(n log n) - Linear logarithmic (merge sort)

O(n²) - Quadratic (nested loop)

O(n³) - Cubic

O(2ⁿ) - Exponential (brute force)

O(n!) - Factorial

Real Impact: Untuk n=1,000,000: O(n) = 1 juta ops (instant), O(n log n) = 20 juta ops (instant), O(n²) = 1 trillion ops (seconds to minutes), O(2ⁿ) = impossible.

Easy

5.2 NP Completeness & Optimization Problems

NP (Nondeterministic Polynomial time) adalah class dari problems di mana solusi dapat di-verify dalam polynomial time. NP-Complete problems adalah hardest problems dalam NP. Jika salah satu NP-Complete problem dapat di-solve dalam polynomial time, maka semua dapat diselesaikan (P = NP).

Problem Classes:

P: Dapat di-solve dalam polynomial time

NP: Solusi dapat di-verify dalam polynomial time

NP-Complete: Semua NP problems dapat di-reduce ke ini

NP-Hard: Minimal sesulit NP-Complete (mungkin harder)

Famous NP-Complete Problems: Traveling Salesman Problem (TSP), Knapsack Problem, Graph Coloring, SAT (Boolean Satisfiability). Solusi optimal memerlukan exponential time.

Hard

5.3 Recursion & Recursion Tree Analysis

Recursion adalah technique di mana function memanggil dirinya sendiri. Recursion tree adalah visual representation untuk analyze complexity dari recursive algorithms. Master Theorem dapat digunakan untuk solve recurrence relations.

JavaScript - Recursion Complexity Analysis 
// Linear: O(n)
function linearRecursion(n) {
    if (n <= 0) return;
    console.log(n);
    linearRecursion(n - 1);
}

// Binary: O(2^n) - exponential!
function fibonacci(n) {
    if (n <= 1) return n;
    return fibonacci(n-1) + fibonacci(n-2);
}

// Binary tree: O(log n) dengan memoization
const memo = {};
function fibMemo(n) {
    if (n in memo) return memo[n];
    if (n <= 1) return n;
    
    let result = fibMemo(n-1) + fibMemo(n-2);
    memo[n] = result;
    return result;
}

// Merge Sort: O(n log n)
function mergeSort(arr) {
    if (arr.length <= 1) return arr;
    
    let mid = Math.floor(arr.length / 2);
    let left = mergeSort(arr.slice(0, mid));
    let right = mergeSort(arr.slice(mid));
    
    return merge(left, right);
}

Chapter 6: Cryptography Mathematics

Security, Encryption & Privacy

6.1 Modular Arithmetic & RSA

Modular arithmetic adalah arithmetic pada integers modulo n. RSA encryption bergantung sepenuhnya pada computational difficulty dari factoring large numbers. RSA adalah foundation dari modern public-key cryptography dan digunakan di HTTPS, digital signatures, dan blockchain.

RSA Key Generation:

1. Choose two large primes p dan q

2. n = p * q (public modulus)

3. φ(n) = (p-1)(q-1) (Euler's totient)

4. Find e (1 < e < φ(n)) dengan gcd(e, φ(n)) = 1

5. Find d: (e * d) mod φ(n) = 1

Encryption: c = m^e mod n

Decryption: m = c^d mod n

Industry Impact: Setiap HTTPS connection yang anda lakukan menggunakan RSA untuk secure key exchange. Banking, e-commerce, dan komunikasi sensitive semua bergantung pada hardness dari integer factorization.

Hard

6.2 Prime Numbers & Number Theory

Prime numbers adalah integers lebih dari 1 yang hanya divisible oleh 1 dan dirinya sendiri. Fundamental Theorem of Arithmetic menyatakan setiap integer dapat di-uniquely factored menjadi primes. Primality testing dan efficient prime generation adalah critical untuk cryptography.

JavaScript - Prime Number Generation 
// Efficient primality test (Miller-Rabin)
function isPrime(n, k = 5) {
    if (n < 2) return false;
    if (n === 2 || n === 3) return true;
    if (n % 2 === 0) return false;
    
    // Write n-1 as 2^r * d
    let d = n - 1;
    let r = 0;
    while (d % 2 === 0) {
        d /= 2;
        r++;
    }
    
    // Witness loop
    for (let i = 0; i < k; i++) {
        let a = 2 + Math.floor(Math.random() * (n - 4));
        let x = modPow(a, d, n);
        
        if (x === 1 || x === n - 1) continue;
        
        let composite = true;
        for (let j = 0; j < r - 1; j++) {
            x = modPow(x, 2, n);
            if (x === n - 1) {
                composite = false;
                break;
            }
        }
        if (composite) return false;
    }
    return true;
}

// Modular exponentiation: (base^exp) mod mod
function modPow(base, exp, mod) {
    let result = 1;
    base = base % mod;
    while (exp > 0) {
        if (exp % 2 === 1) result = (result * base) % mod;
        exp = Math.floor(exp / 2);
        base = (base * base) % mod;
    }
    return result;
}
Hard

6.3 Elliptic Curve & Modern Cryptography

Elliptic Curve Cryptography (ECC) adalah modern alternative ke RSA yang provide same security dengan much smaller key sizes. ECC equations: y² = x³ + ax + b. ECDSA (Elliptic Curve Digital Signature Algorithm) digunakan untuk cryptocurrency signatures dan TLS certificates.

Elliptic Curve Equation:

y² ≡ x³ + ax + b (mod p)

Point Addition (Group Law):

P + Q = R (defined geometrically)

P + P = 2P (point doubling)

Security Basis:

Elliptic Curve Discrete Logarithm Problem (ECDLP)

Bitcoin & Blockchain: Bitcoin menggunakan secp256k1 elliptic curve. Private key (256 bits) dapat generate public key via curve multiplication. Security dari billions of dollars di blockchain bergantung pada hardness dari ECDLP.

Hard

Chapter 7: Numerical Methods

Computational Mathematics & Simulation

7.1 Newton-Raphson & Root Finding

Newton-Raphson adalah iterative method untuk finding roots (zeros) dari functions. Digunakan extensively dalam scientific computing, physics simulations, dan optimization. Convergence sangat cepat (quadratic) jika initial guess cukup dekat dengan root.

Newton-Raphson Formula:

xₙ₊₁ = xₙ - f(xₙ) / f'(xₙ)

Iterasi sampai |xₙ₊₁ - xₙ| < ε (tolerance)

JavaScript - Newton-Raphson Implementation 
// Find root dari f(x) = x^2 - 2 (sqrt(2))
function newtonRaphson(f, fPrime, x0, epsilon = 1e-6, maxIter = 100) {
    let x = x0;
    
    for (let i = 0; i < maxIter; i++) {
        let fx = f(x);
        let fpx = fPrime(x);
        
        if (Math.abs(fpx) < 1e-10) {
            console.log("Derivative too small, cannot continue");
            break;
        }
        
        let xNext = x - fx / fpx;
        
        console.log(`Iteration ${i}: x = ${x}, f(x) = ${fx}`);
        
        if (Math.abs(xNext - x) < epsilon) {
            console.log(`Converged to root: ${xNext}`);
            return xNext;
        }
        
        x = xNext;
    }
    
    return x;
}

// Example: Find sqrt(2)
let f = x => x * x - 2;
let fPrime = x => 2 * x;
let root = newtonRaphson(f, fPrime, 1.5);
// Output: approximately 1.41421356 (sqrt(2))
Medium

7.2 Numerical Integration & Interpolation

Numerical integration adalah approximation dari definite integrals ketika analytical solution tidak possible. Interpolation adalah estimasi dari function values di points yang tidak dalam dataset. Keduanya fundamental dalam scientific computing, physics simulation, dan data analysis.

Trapezoidal Rule:

∫ᵃᵇ f(x)dx ≈ (b-a)/2 * [f(a) + f(b)]

Simpson's Rule:

∫ᵃᵇ f(x)dx ≈ (b-a)/6 * [f(a) + 4f((a+b)/2) + f(b)]

Lagrange Interpolation:

L(x) = Σ yᵢ * Lᵢ(x) where Lᵢ(x) = ∏(x - xⱼ)/(xᵢ - xⱼ)

JavaScript - Simpson's Rule Integration 
function simpsonsRule(f, a, b, n = 100) {
    // n harus even
    if (n % 2 !== 0) n++;
    
    let h = (b - a) / n;
    let sum = f(a) + f(b);
    
    // Odd indices: coefficient 4
    for (let i = 1; i < n; i += 2) {
        sum += 4 * f(a + i * h);
    }
    
    // Even indices: coefficient 2
    for (let i = 2; i < n; i += 2) {
        sum += 2 * f(a + i * h);
    }
    
    return (h / 3) * sum;
}

// Contoh: integrate sin(x) dari 0 sampai π
let result = simpsonsRule(Math.sin, 0, Math.PI, 1000);
console.log(`∫₀^π sin(x)dx ≈ ${result}`);
// Expected: approximately 2.0
Hard

7.3 Floating Point Error & Stability

Computer numbers tidak dapat represent semua real numbers dengan perfect precision. Floating point arithmetic introduce errors melalui rounding, truncation, dan accumulation. Understanding ini crucial untuk scientific computing di mana small errors dapat accumulate menjadi large inaccuracies.

IEEE 754 Double Precision:

1 sign bit + 11 exponent bits + 52 mantissa bits = 64 bits

Range: ≈ ±10^±308 dengan 15-17 significant digits

Machine Epsilon (ε):

Smallest x di mana 1 + x ≠ 1

Untuk double: ≈ 2.22 × 10^-16

Numerical Stability Example: Calculating y = x + 1 - x dalam floating point bisa give hasil yang salah. Jika x sangat besar, maka x + 1 = x (due to precision limits), sehingga result adalah 0 bukan 1. Solution: reformulate problem secara algebraic atau gunakan higher precision.

Hard
